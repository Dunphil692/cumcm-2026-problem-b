# 问题四代码：类型感知的多源融合定位与清除策略

本包是问题四的**本地仿真实现**（不连官方模拟器），在问题三 belief v2 骨架上实现：

1. **双假设集员滤波**：全向假设（no_signal 挖 990 m 洞，问题三机制）与定向假设
   （no_signal 不剪裁位置）分离；听见后补测站测到 no_signal 计为**定向证据**。
2. **定向完备普查网**：内网 13 点（圆心 + 900@0° + 1350@30°）+ 按需外环 12 点
   （1900@15°）。25 m 格点 / 1° 朝向网格验证：内网+外环盲区测度 **0.0000%**，
   全向覆盖 100%（最远 900 m）——全网沉默 ⇒ 频道认证为空（零漏检证书）。
3. **检测概率加权补测**（简化 E-IG）：候选站按 `((180−δ)/180)^(1+证据数)` 加权，
   定向源重试自动偏向小偏移角站。
4. **四态楔形追踪**（定向源兜底）：A 60 m 步前进 → B 折返（跨过源后在近侧
   捕获 5 m near）→ C 垂直切入扇区内部（对付擦边出扇）→ D 4 m 步内部逼近。
   数学依据：沿示向原点射线 dir(g→dog) 恒定；越源后翻转 180° 落出 ±90° 扇区；
   擦边原点（扇区边距 < ~10°）会在中途侧向出扇，需垂直切入重建边距。
5. 其余（探点、精测逼近、兜底、开放 Held–Karp/TSPN 每停重解、同站测清合并、
   听到 16 只停普查）沿用问题三 v2。

## 实现要点备忘（调试血泪）

- **同点重复测量不重采样** ±1° 误差：所有新观测必须换站（候选点距旧站 ≥40 m）。
- **no_signal 对定向源几乎无信息**：绝不能像问题三那样把 B(S,990) 挖进
  已听见频道的可行集；只有"距可能样本 ≤990 m 的补测站测到 no_signal"
  才是强定向证据。
- **沿射线追踪越过源后出扇**：远侧 no_signal 是"跨过源"信号，不是失败；
  但擦边原点会中途侧向出扇——两种 no_signal 必须区分（B 态 vs C 态）。
- **任务池每停重建**：homing/probe 等一次性任务的"已执行"标记必须打在
  **执行时**（主循环 pick 分支），打在创建时会让任务蒸发或无限重提。
- **外环站点的追踪目标不能 clip 回圆内**：会把方向拉偏出扇。
- 误差按 (频道, 站点) 缓存 ⇒ 同点重复测返回相同结果（与官方行为一致）。
