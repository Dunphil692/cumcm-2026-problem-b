## 模型（一句话）

源域 \(\Omega_1=B(O,1800)\cap W(S_1,\theta_1,1^\circ)\cap\{5<d_1\le1500\}\)（逐方向裁剪）→ 一般保证接收域 \(C_{\rm recv}=\{q:\sup_g(\|q-g\|-\max(1000,d_1))\le0\}\) → 目标 \(J(q)=\sup_{g,e_2}\mathrm{diam}(W_1\cap W_2\cap\Omega_1\cap\{5<d_2\le1500\})\)。

## 修正记录（v2 相对旧稿）

1. **后验裁剪修正**：旧稿只算 \(W_1\cap W_2\) 裸直径，把 \(d_1>1500\) m 的不可能源点算进直径 → 135 m 虚高约 20%；裁剪后 112.1 m，重新寻优得 **110.97 m**。
2. **接收口径升级**：三圆叶子（d2≤1000 全源）改为严格的一般保证接收（\(d_2\le\max(1000,d_1)\)）；三圆保留为保守充分条件。
3. **近场分支**：d2≤5 m 时计算 \(\Omega_1\cap B(q,5)\) 的真实交集（旧稿记 +∞）。
4. **切向对称性修正**：切向场景楔形轴镜像点在目标圆外，候选区只有西侧一瓣（南侧 J≈40 m，非最优）。
5. 交叉验证：与独立实现（Shapely/GEOS、4096 源、129 误差）三场景直径差 ≤ 0.006 m。

## 诚实边界（论文中应保留的表述）

\(J\) 是有限源/误差网格上的最坏值，**非连续上确界认证**；最优点为数值寻优结果，**连续全局最优未认证**；1.25 是建模容差，不是题面常数。
