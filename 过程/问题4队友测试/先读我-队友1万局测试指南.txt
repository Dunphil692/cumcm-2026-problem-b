算法本地大规模蒙特卡洛仿真测试包（1,000 ~ 10,000 轮）

一、这是什么
--------------------------------------------------------------------------------
这是问题 4 刚刚在官方模拟器打出极佳实测成绩（10源 5517s、16源 6590s、顶格全清）
的最新算法定稿包：
【N19 扇区单向延迟收割 + 奔袭静默免听 双优化架构】。

用于在本地电脑（Windows / Mac / Linux 均可）多进程并发跑 1,000 ~ 10,000 轮
蒙特卡洛仿真，自动输出论文正文主表所需的：
- 满额全清率 (Full Clear Rate)
- 干扰源总清除率 (Overall Clear Rate)
- 定向源专项清除率 (Directional Clear Rate)
- 平均总搜索用时 ± 标准差
- 中位数搜索用时 (Median)
- 单源平均清除时间 (秒 / 源)
- 平均移动路程 (米) 与 平均测向次数


二、环境准备
--------------------------------------------------------------------------------
1. Python 3.10 及以上
2. 依赖库仅需 numpy：
   pip install numpy


三、如何运行（三步走）
--------------------------------------------------------------------------------
打开终端（Windows 的 CMD 或 PowerShell），进入解压后的 code 目录：
cd 发给队友-问题4-1万局测试/code

【第一步：10 秒冒烟测试（验证环境）】
   python test_smoke.py
   看到 "PASS! 1 trial completed..." 即可。

【第二步：执行蒙特卡洛仿真】

★ 强烈推荐（赛时极速 1000 轮，约 15 分钟）：
   python run_q4_monte_carlo.py --n 1000 --workers 8

   说明：
   在大数定律下，1000 轮的大样本统计误差已低于 0.1%，对于数学建模论文正文
   的核心主表而言，1000 轮的数据置信度和权威性完全足够！
   8 核心大约 15 分钟即可跑完，可以立即提供给执笔同学填表定稿，绝不耽误 20:00 截稿！

★ 顶格 10,000 轮测试（耗时约 2 ~ 2.5 小时）：
   python run_q4_monte_carlo.py --n 10000 --workers 8

   说明：
   如果电脑核心数较多（如 12 核、16 核，可指定 --workers 12 / 16），速度会更快。
   终端每完成 250 局会自动打印一次实时进度与剩余预计时间。


四、输出成果与论文对接
--------------------------------------------------------------------------------
运行结束后：
1. 终端会直接打印排版工整的 Markdown 统计大表，可直接 Ctrl+C / Ctrl+V 复制进论文！
2. 结果自动保存在 results/ 目录下：
   - 逐局详细 CSV：results/q4_n19_mc_XXXX_trials.csv
   - 汇总统计 JSON：results/q4_n19_mc_XXXX_summary.json
   可直接打包进论文的“支撑材料”压缩包中作为大样本仿真凭据。

祝论文写作顺利，圆满交卷！
