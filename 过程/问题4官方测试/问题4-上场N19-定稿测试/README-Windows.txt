一、 方案确认与性能指标
--------------------------------------------------------------------------------
本文件夹包含问题 4 经严格配对验证的最佳上场算法：
- 架构：N19 普查网 (原点 + 内圈 1000m 正六边形 + 外环 12 站 @ 1825m)
- 核心机制：
  1. 【逆时针单向顺流推进】：顺接内圈角动量，彻底杜绝逆向掉头；
  2. 【1300m 扇区单向延迟收割】：身后远端目标暂缓，等巡检顺流自然收割，防跨半球折返跑；
  3. 【奔袭转场静默免听】：转场与补站点只测追踪源，砍掉 8~10 个无声频道的无效盲测；
- 实测表现：100% 满额全清，单源平均时间 520~575 s/源，局均较原版少走 4.2 公里。


二、 运行环境要求
--------------------------------------------------------------------------------
1. Python 3.10 及以上
2. 依赖库仅需 numpy：
   pip install numpy


三、 Windows 模拟器联调与测试步骤
--------------------------------------------------------------------------------
【第一步：登录模拟器并就绪】
1. 打开官方模拟器程序，使用你们队伍的参赛队号登录；
2. 模拟器界面先点击「问题4演练测试」（注意：先点演练！等待 5 秒倒计时结束，状态显示接口就绪）。

【第二步：打开 Windows 终端执行】
打开 Windows 命令提示符（CMD）或 PowerShell，进入本解压目录：
   cd /d 你的文件夹路径

设置队号环境变量（必须与模拟器登录队号完全一致）：
   CMD 用户：
      set CUMCM_ROBOT_ID=你们的参赛队号

   PowerShell 用户：
      $env:CUMCM_ROBOT_ID="你们的参赛队号"

先跑 10 秒冒烟测试（验证 HTTP 连通性与指令）：
   python run_official_smoke.py
   （看到输出各项指令且虚拟时间约 199 秒退出即表示连接正常）

跑演练完整一局（可选，若之前已跑通可直接进入正式）：
   python run_official_n19.py
   （终端会实时推进，跑完 100% 满额全清后自动正常退出）

【第三步：正式交卷测试（第 2 次、第 3 次）】
当演练确认正常后，开始进行正式测试交卷：
1. 在模拟器界面点击「问题4正式测试」（等待 5 秒倒计时结束）；
2. 在命令行窗口直接回车执行：
   python run_official_n19.py
3. 运行完毕后，模拟器会自动生成正式的 .jlog 日志并显示在成绩表上；
4. 再次点击「问题4正式测试」，重复执行一次，跑满 3 次正式测试！


四、 赛后材料封存
--------------------------------------------------------------------------------
1. 跑完 3 次正式测试后，在模拟器软件所在目录下的 log/ 文件夹中，
   找到 3 份生成的 .jlog 正式日志文件；
2. 将这 3 份 .jlog 文件复制出来，放入论文提交的“支撑材料”压缩包中；
3. 将模拟器界面显示的第 1、2、3 次测试的虚拟用时、单源平均时间填入论文正文【表 1】中。

祝正式测试顺利，取得优异成绩！
